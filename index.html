Which games work here?
This room runs WebAssembly games that implement the Local Game ABI v1: an RGBA display, text status and input events. It does not run native desktop or Amiga executables directly.
Keyboard input goes to the focused game screen. On phones, Play view fits the display and touch controls around the available screen, including the on-screen keyboard. Type text and Numbers open their input controls. Exit play view returns to file controls without restarting. Right click uses the most recent pointer position. Stop clears the running game; Start creates a fresh instance.
