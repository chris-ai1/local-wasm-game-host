Which games work here?

This room runs WebAssembly games that implement the Local Game ABI v1: an RGBA display, text status and input events. It does not run native desktop or Amiga executables directly.

Keyboard input goes to the focused game screen. The touch keyboard and buttons also work on mobile. Right click uses the most recent pointer position. Stop clears the running game; Start creates a fresh instance.
